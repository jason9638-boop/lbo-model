        計算邏輯

        • 進場企業價值 = 進場 EBITDA × 進場倍數；債務 = 企業價值 × 舉債比例；股權投入 = 企業價值 − 債務。
        • 每年 EBITDA 依成長率成長；利息 = 期初債務 × 利率；可用現金流 = EBITDA × 轉換率 − 利息。
        • 可用現金流優先償還債務，債務還清後的剩餘現金累積於公司；若可用現金流為負，不足額以新增借款支應。
        • 出場股權價值 = 出場年 EBITDA × 出場倍數 − 債務餘額 + 累積現金。
        • MOIC = 出場股權價值 ÷ 股權投入；因假設持有期間無股利分配，IRR = MOIC1/年限 − 1。

        評分標準（滿分 100）

        • IRR（35 分）：IRR 達「門檻 + 5 個百分點」得滿分，0% 以下得 0 分，中間線性給分。
        • MOIC（15 分）：2.5 倍得滿分，1.0 倍以下得 0 分。
        • 進場槓桿（15 分）：債務 ÷ EBITDA 在 4 倍以下得滿分，7 倍以上得 0 分。
        • 利息保障（15 分）：持有期間最低的 EBITDA ÷ 利息達 4 倍得滿分，1.5 倍以下得 0 分。
        • 報酬品質（20 分）：倍數擴張占增值比例越低越好（12 分，占比 60% 以上得 0 分）；EBITDA 成長率 8% 以下得滿分，20% 以上得 0 分（8 分）。
        • 上限規則：IRR 未達門檻時總分最高 69 分（最多 C 級）；出場股權價值歸零時直接評為 F。
        • 等級：A ≥ 85、B 70–84、C 55–69、D 40–54、F < 40。

        評分門檻為本工具為教學目的自行設定，並非業界統一標準。模型未考慮交易費用、稅負細節、管理層持股與分期債務條件，僅供學習使用，不構成投資建議。
